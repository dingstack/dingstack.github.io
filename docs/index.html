BTF(Binary Tree File)

BTF是一个基于路径的键值数据库文件格式，它提供了基于路径的访问方式，形成了一个二进制树结构文件。btf是在单个文件的基础上，实现了一个小型文件系统，它的基本存储单元称为节点inode。inode有7种类型，分别是bool,int,int64,double,string,dir,array，其中dir和array是存储子节点的容器节点，其他的是叶子节点。btf有个一个根目录节点，它的ID值为0，对应的路径名为'/'。子节点可以通过路径的方式进行访问，例如：/dira/b,dira/c.txt。
